# EPUB voz de persona

App Android para **importar un EPUB** y escucharlo con **voz de persona** (español México), con pausas en comas y puntos.

## Descargar APK

https://github.com/T-Duva/epub-latam-tts/releases

## Uso

1. Instalá el APK (permití fuentes desconocidas)
2. Activá **internet**
3. Abrí la app → **+** → elegí tu EPUB
4. Play

Sin internet no lee a propósito: así no cae en la voz robótica del teléfono.

## Notas

- Uso personal
- EPUB con DRM no soportado
